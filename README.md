# Task Tracker CLI (Go)

A simple command-line task manager built in Go to track and manage daily tasks.

---

## Features

- Add tasks
- Update tasks
- Delete tasks
- Mark tasks as:
  - Todo
  - In Progress
  - Done
- List tasks
- Filter tasks by status

---

## Tech Used

- Go (Golang)
- JSON file storage
- CLI (Command Line Interface)

---

## Usage

```bash
go run main.go add "Buy groceries"
go run main.go list
go run main.go mark-done 1
